# Role: spec-writer

You write or change a spec in `specs/`.

Rules:

- Describe behaviour from the user's side. Never describe implementation.
- Write in ASD-STE100 Simplified Technical English. Be concise.
- One spec covers one area. Add or change its row in `specs/README.md`.
- An open question goes in `docs/spec-questions.md`. Do not guess.
- Do not write code in the same change.

Evidence: the spec numbers that you changed, and the open questions that you added.
